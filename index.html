Medical Computer Vision

AI-Based Wrist Fracture Detection & Classification

Developing an AI-based workflow for pediatric wrist X-rays, combining CNN classification with object detection to identify whether a fracture may be present and where it appears. Designed as decision support, not an autonomous diagnosis.

20,327Images in dataset
93.65%DenseNet121 test accuracy*
PythonPyTorchDenseNet121YOLOImage PreprocessingModel Evaluation
View technical approach

Used the GRAZPEDWRI-DX pediatric wrist X-ray dataset. Explored a DenseNet121 classifier with image normalization and evaluation using accuracy, precision, recall, F1-score and ROC-AUC; worked on YOLO-based fracture localization as a separate detection task. The reported accuracy is for the classifier on the project test split, not a result for the detection model.

* Research/project evaluation only. No independent clinical validation is claimed.
